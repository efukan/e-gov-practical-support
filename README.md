# e-Gov 法令検索 実務サポート (e-Gov Law Search Practical Support)

e-Gov法令検索（laws.e-gov.go.jp / elaws.e-gov.go.jp）で条文を読むときの、行ったり来たりを減らす Google Chrome 拡張機能です。

---

## 🌟 主な機能

1. **横書き表記変換**
   * 漢数字による条文番号や法令番号、引用表記（「前二条」「次三項」などの順方向・逆方向参照含む）を、実務に適した「算用数字（全角）」に動的変換します。
   * 例：`第七十七条の三十五の七` ➔ `第７７条の３５の７`（多段階の枝番やIDの表記揺れにも対応）
   * 号の見出しを半角カッコ書きに変換します。例：`一` ➔ `(1)`、`一の二の三` ➔ `(1)の2の3`
2. **括弧書きの薄字化**
   * 本文内の補足や例外規定を表す括弧書き（`（...）`）を自動検出し、テキストを薄字（グレー）化します。さらに括弧自体に色をつけることで強調を抑え、主文の速読と正確な把握を助けます。
3. **参照条文ポップアップ**
   * 本文内に登場する同一法令内の「第〇条」リンクはもちろん、他の法令への参照リンク（例: 「民法第七百九条」「地方自治法第十条」など）も、マウスホバーするだけで参照先条文の本文テキストをその場でポップアップ表示します。
   * 長い条文もポップアップ内でスクロールして続きまで読めます。読書中のマウス通過による誤表示を防ぐため、約0.3秒の表示遅延を設けています。
   * ポップアップ右上のボタンから、同一法令内なら該当条文へ直接スクロール移動（ジャンプ）、他法令なら新しいタブで開くこともできます。
4. **定義語ホバー辞書**
   * 法令内で定義されている定義語（例：「「道路」とは、...をいう。」）を検知して下線を付与し、マウスホバー時にその定義された条文をポップアップで辞書のように表示します。
5. **目次の自動追従 (ScrollSpy)**
   * 本文のスクロール位置を検知し、目次の該当箇所をリアルタイムに自動強調表示（ハイライト）することで、長大な法令内での現在地を常に把握しやすくします。
6. **条文ジャンプ検索**
   * 画面右上に常時表示される入力欄に条文番号（例: 「5」「12の2」）を入力して Enter を押すだけで、該当条文の位置へ瞬時に高速スクロール（ジャンプ）します。高速レンダリング有効時も位置ズレなく正確に着地します。
7. **他法令リンクの別タブ展開**
   * 本文内にある他法令への参照リンクをクリックした際、現在の表示を切り替えずに自動的に新しいタブで開き、並行した調査や比較を容易にします。
8. **高速レンダリング**
   * 画面外にあって見えていない条文ブロックの描画計算を省略することで、ページの初期表示速度とスクロール操作の滑らかさを向上させます。
9. **被引用（引用元）表示**
   * 他の法令から引用・参照されている条文タイトルの右隣に「引用」ボタンを自動挿入します。
   * ボタンにマウスホバーすることで、その条文を引用している他法令（施行令・施行規則など）の一覧がポップアップで表示されます。
   * 一覧内の条文リンクにマウスを乗せると、該当条文の本文が横にフライアウト表示され、引用箇所が自動ハイライトされます（HTML形式の法令も公式XML APIから自動補完）。ポップアップ右上のボタンから該当条文を別タブで開くことも可能です。また、プレビュー内の条文には引用ボタンが混入しないよう配慮されています。

## 🚀 インストール方法

本拡張機能は、通常利用向けに **Chrome ウェブストア** でも公開されています。手軽に利用したい場合は、ウェブストア版のインストールを推奨します。

👉 **[Chrome ウェブストア - e-Gov 法令検索 実務サポート](https://chromewebstore.google.com/detail/mpanmbfnofadfdjikanogjppeabhkkld?utm_source=item-share-cb)**

本GitHubリポジトリで公開されているコードは、この拡張機能のソースコード（オープンソース版/開発版）です。ソースコードから直接ローカルにインストールしてテストや開発を行いたい場合は、以下の手順に従ってください。

### 🛠️ ローカルでの手動インストール手順

1. 本リポジトリ（フォルダ）を任意のローカルディレクトリにダウンロードまたは配置します。
2. Google Chrome を起動し、アドレスバーに `chrome://extensions/` を入力して拡張機能管理画面を開きます。
3. 画面右上にある **「デベロッパー モード」** トグルをオンにします。
4. 画面左上に表示される **「パッケージ化されていない拡張機能を読み込む」** ボタンをクリックします。
5. 本プロジェクトのルートディレクトリ（展開したフォルダ）を選択して読み込みます。
6. インストール完了後、e-Gov法令検索の条文表示ページを開くと、自動的に拡張機能が有効になります。

## 🧪 開発とテスト (Development)

本拡張機能はビルド不要です。ソースをそのまま `chrome://extensions/` から読み込めます。
テストと開発用ツールのみ Node.js に依存しています。

```bash
npm install
```

### テストの実行

```bash
npm test
```

以下の2つが実行されます（いずれも jsdom 上で動作し、ブラウザは不要です）。

* `tests/smoke_content_scripts.js` — `manifest.json` に記載された順序で content script 一式を読み込み、定義語の抽出からハイライト、ホバー表示、元の状態への復元までを一通り検証します。
* `tests/test_tooltip_position.js` — ホバーポップアップの配置ロジック（画面端での上下反転・左右の収まり・矢印の位置）を検証します。

### アイコンの再生成

`icons/icon.svg` を更新した場合は、以下で各解像度の PNG を生成します。

```bash
npm run generate-icons
```

### 変更履歴

各バージョンの変更点は [CHANGELOG.md](CHANGELOG.md) を参照してください。
